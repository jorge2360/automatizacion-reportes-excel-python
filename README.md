# Automatización de Reportes Excel con Python

Proyecto de automatización para procesar datos empresariales, generar reportes en Excel y crear gráficos básicos utilizando Python.

## Tecnologías

- Python
- pandas
- openpyxl
- matplotlib
- Excel

## Objetivo

Automatizar la generación de reportes a partir de archivos CSV, aplicando limpieza de datos, análisis básico y exportación a Excel.
